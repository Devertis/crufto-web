What Crufto Cleaner finds

One scan, sorted by where the space actually is — not a single “junk” pile.

  • Developer clutter

    node_modules, Xcode DerivedData, build folders, old simulators and SDKs.

  • Package caches

    npm, pip, Homebrew, Gradle and friends — re-downloaded only when a project needs them.

  • Caches & junk

    Stale application caches and logs that quietly grow for months.

  • App leftovers

    The support files, caches and preferences apps leave behind after you delete them.

  • Large & old files

    Big files you haven't opened in a year, grouped so you can skim and decide.

  • System Data, decoded

    Swap, snapshots, boot files and purgeable space — the pile Finder just labels “System Data.”

Built for developers

The gigabytes your tools leave behind.

If you write code, your disk fills faster than anyone's. Crufto Cleaner understands the difference between source you need and output you can regenerate — and never touches your code.

  • Build folders in inactive projects — your code is untouched
  • Xcode build files, device support & simulators
  • Docker disks, VMs and downloaded AI/ML models
  • Old Node, Python, Ruby, Java & Android SDK versions

Coming to the Mac App Store

Why the gap? Every Mac App Store app must run in Apple's sandbox, which forbids reading your whole disk. The complete edition isn't sandboxed, so it can see everything and do the full job — which is why serious Mac cleaners are distributed directly, the way the complete edition is.
