# crufto-web

Marketing + download site for **crufto.com** — the home of [Crufto Cleaner](https://crufto.com),
a fast, safe macOS storage cleaner.

Static site served by nginx. Deployed on Coolify (build pack: Dockerfile).

```
site/
  index.html              landing page
  styles.css
  assets/                 app icon + favicon
  downloads/              the notarized Crufto Cleaner DMG
Dockerfile                nginx:alpine serving site/
```
